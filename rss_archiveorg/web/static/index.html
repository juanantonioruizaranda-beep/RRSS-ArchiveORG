Localhost y proxys: cómo funciona esta versión

Esta landing es la interfaz web del extractor que también puedes lanzar en localhost. El servidor corre en tu máquina y las peticiones a archive.org salen desde ahí, con la misma lógica de proxys que la versión CLI.

Arrancar en localhost

source .venv/bin/activate
python -m rss_archiveorg.web

Abre http://localhost:8000 y usa el formulario de arriba.

Proxys rotativos (opcional)

Si archive.org devuelve errores 429 Too Many Requests, activa proxys para repartir el tráfico y rotar automáticamente ante bloqueos o fallos temporales.

  1. Marca Usar proxys rotativos en el formulario
  2. Pega tus proxys en el cuadro de texto, uno por línea: host:puerto o host:puerto:usuario:contraseña
  3. Opcional en localhost: crea proxies.txt desde proxies.example.txt si prefieres un archivo en el servidor

Comportamiento con proxys activos:

  • Rotación round-robin entre cada sitio del lote
  • Nuevo proxy automático ante 429 o errores 5xx
  • Las credenciales no se muestran en logs ni en la interfaz
  • Sin proxys, usa la espera entre peticiones (mín. 3 s) para reducir bloqueos

Equivalente por CLI

python -m rss_archiveorg sites.txt --proxies proxies.txt --delay 5 -v

La landing reutiliza el mismo motor de extracción, proxys y reintentos.
